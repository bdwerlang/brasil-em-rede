# Workflows anteriores, inativos

Os YAMLs deste diretório são referências históricas fora de `.github/workflows`.
Incluem publicação de imagens/releases, governança de PRs, deploy SSH,
rotulagem e auditorias agendadas com acesso às fontes.

Sua reativação exige uma PR que adapte o workflow ao novo repositório e
justifique permissões, credenciais, custos e efeitos. A configuração inicial
ativa está em [`.github/workflows`](../../../.github/workflows).
