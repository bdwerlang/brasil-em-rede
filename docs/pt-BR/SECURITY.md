# Política de segurança — Brasil em Rede

Policy-Version: v1.1.0
Effective-Date: 2026-10-27
Owner: mantenedores do repositório

## Reporte de vulnerabilidades

Quando disponível, use a aba `Security` → `Report a vulnerability` deste
repositório. Se o canal privado estiver indisponível, abra uma issue pedindo
contato privado, sem detalhes de exploração ou registros sensíveis.

## Versões suportadas

O desenvolvimento ocorre em `main`. Ainda não há release de produção suportada.
Os snapshots anteriores não estabelecem suporte de produção para esta
continuação. Veja [NOTICE.md](../../NOTICE.md).

## Prazos de resposta

Ainda não há SLA definido. Os mantenedores devem confirmar e avaliar relatos
conforme capacidade e registrar versão afetada, reprodução e mitigação no
relato privado. Não publique detalhes de exploração antes da triagem.
