# Security policy — Brasil em Rede

Policy-Version: v1.1.0
Effective-Date: 2026-10-27
Owner: repository maintainers

## Reporting vulnerabilities

Use GitHub Security Advisories for responsible disclosure:

- Private report path, when enabled: this repository's `Security` tab -> `Report a vulnerability`.
- If private reporting is unavailable, open an issue asking for a private contact
  without including exploit details or sensitive records.
- Do not disclose exploit details publicly before triage.

## Supported versions

Development happens on `main`. There is no supported production release yet.
Changes are reviewed on a best-effort basis; inherited snapshots are not a
statement of production support. See [NOTICE.md](NOTICE.md).

## Disclosure SLA targets

Response targets have not been established for this independent continuation.
Maintainers should acknowledge and triage reports as capacity allows, and
record the affected version, reproduction and mitigation in the private report.

If a report is out of scope or non-actionable, rationale will be documented in the advisory workflow.
